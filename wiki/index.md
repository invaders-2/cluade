# Wiki 导航首页 / 地图

> 只标分区、项目列表、资料位置，**不存具体内容**（具体内容进对应分区）。规则见根 `CLAUDE.md` §5。

## 八大模块
| 模块 | 用途 |
|------|------|
| `index.md` | 本页：导航地图 |
| `schema.md` | 制度宪法：命名/权限/规范 |
| `system/` | 全局管理：看板、操作日志、记忆路由、技能分配、评分账本 |
| `projects/` | 项目专区（每项目独立分区，模板见 `projects/_template/`） |
| `pages/` | 跨项目、已验证的通用方法论 |
| `raw/` | 一手原始素材（只读不改） |
| `assets/` | 图片 / 图表 / 架构图 |
| `archive/` | 过期项目、废弃方案、老草稿 |

## 角色配置
四个 Profile 在仓库根 `profiles/`：coordinator / researcher / writer / builder。

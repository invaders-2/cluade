# 记忆路由表（防污染核心）

> 写任何信息前先查这张表决定它去哪。没有归属的信息不准落盘。完整版见根 CLAUDE.md §6。

| 信息类型 | 去处 |
|---------|------|
| 角色身份/职责/禁区 | `profiles/<角色>/soul.md` |
| 角色通用方法论 | `profiles/<角色>/memory.md` |
| 密钥/凭证 | `profiles/<角色>/.env`（不入库） |
| 草稿、未验证资料 | `projects/<项目>/inbox/` |
| 已核验、可交付产出 | `projects/<项目>/outputs/` |
| 项目既定方向 | `projects/<项目>/已定决策.md` |
| 跨项目通用知识 | `pages/` |
| 一手原始素材 | `raw/`（只读） |
| 图片/图表 | `assets/` |
| 过期/废弃 | `archive/` |
